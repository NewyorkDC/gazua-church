# ⛪ 가즈아 교회

온라인 법당(코루라이브 / 가즈아법당) 류의 **3D 실시간 멀티플레이 공간**을 교회 버전으로 만든 것.
부처 대신 **트럼프 황금 동상(트황상)** 을 모시고, 네 벽면 전광판에 실시간 주식·코인 시세가 흐릅니다.

```bash
npm install
npm start
# http://localhost:8080
```

---

## 시세는 진짜입니다

Yahoo Finance 공개 chart 엔드포인트에서 **실제 1분봉과 현재가**를 가져옵니다. API 키가 필요 없습니다.

- 갱신 주기 **30초** (`POLL_MS`)
- 거래소에 따라 15분 지연될 수 있습니다
- 못 가져온 종목만 조용히 시뮬레이션으로 떨어지고, 실시간인 종목에는 `LIVE` 배지가 붙습니다
- `LIVE=0 npm start` 로 전부 모의 데이터 전환

| 자리 | 종목 | Yahoo 심볼 |
|---|---|---|
| 북쪽 전광판 | 삼성전자 · SK하이닉스 | `005930.KS` `000660.KS` |
| 남쪽 전광판 | QQQ · SOXX | `QQQ` `SOXX` |
| 동·서 전광판 + 피라미드 | 추천 상위 4종목 | 투표로 교체 |
| 상단 띠 | 비트코인 · 코스피 · 원/달러 · 나스닥 선물 | `BTC-USD` `^KS11` `KRW=X` `NQ=F` |

추천은 **1인 1표**, 5분마다 상위 4종목이 동·서 전광판과 네 구석 피라미드 간판에 올라갑니다.
후보에 없는 티커/종목코드를 직접 넣으면 Yahoo 에서 찾아 붙입니다 (`005930` → `.KS`/`.KQ` 자동 시도, 한글명은 검색).

## 할 수 있는 것

- `WASD` / 방향키 이동 (`Shift` 달리기), 마우스 드래그 시점, 휠 줌, `Space` 점프
- 💩 **오물 던지기** (`R` 또는 버튼 **꾹 누르기**) — 누르고 있으면 조준이 몸통→머리로 올라갑니다.
  충전 중 **포물선 점 궤적**과 착탄 링이 보이고(머리=빨강, 몸통=금색), 누른 채로 드래그하면 좌우 조준.
  명중 판정은 서버가 구 교점으로 계산 — 머리 +3.4%, 몸통 +1.5%
- 🧽 **동상 청소** (`C`) — 동상 반경 5.5m 안에서, 한 번에 **1%**
- 🙏 **기도** (`E`) — 95가지 멘트 중 하나를 랜덤으로 외칩니다 (말풍선만, 채팅창에는 안 남음)
- 🔺 **상승기원** / 🔻 **하락기원** — 우세한 쪽에 따라 트황상 머리 위 태양이 **붉은색/파란색**으로 빛납니다.
  차이가 클수록 밝아지고, 일정 수치를 넘으면 **클럽 조명처럼 빔이 돌며 번쩍**입니다
- 💬 채팅 (`Enter`, 40자) — 말풍선 + 좌측 하단 로그 60줄
- 🕯 **고해소** — 서쪽 기록판에 말풍선으로 붙습니다. 최근 **20개**만 남고 오래된 것부터 삭제
- 🏅 **헌신 순위** — 청소 / 오물 명중 / 머리 명중 상위 5명
- 네 구석 **피라미드 기도단**(점프로 등반), **장의자**도 올라갈 수 있습니다
- 🎧 찬송가 BGM — 오디오 파일 없이 WebAudio 로 파이프오르간 합성 (Amazing Grace, 퍼블릭 도메인)

### 오염도와 붕괴

오물이 쌓이면 동상이 단계적으로 더러워집니다 — 금속광이 사라지고 → 덩어리가 붙고 → 45%에 파리가 꼬이고
→ 70%에 좌대 둘레에 더미가 쌓이고 → 88%에 머리 위에 똥이 얹힙니다.

**100%가 되면 트황상이 쓰러지고 그 자리가 거대한 똥더미로 바뀝니다.**
1분 뒤 깨끗한 몸으로 재건되고, 오염도·얼룩·상승/하락 기원 수치가 전부 초기화됩니다.

### 직위 10단계

헌신 점수 = `청소×2 + 오물명중 + 머리명중×3 + 기도×2 + 머문 시간(분)`

| | 직위 | 필요 점수 | 손에 쥐는 것 | 오라 |
|---|---|---|---|---|
| 1 | 구도자 | 0 | – | – |
| 2 | 새신자 | 8 | – | – |
| 3 | 성도 | 20 | 성경책 | – |
| 4 | 서리집사 | 45 | 성경책 | – |
| 5 | 안수집사 | 85 | 등불 | – |
| 6 | 권사 | 140 | 등불 | – |
| 7 | 장로 | 220 | 나무 지팡이 | 🌌 오로라 |
| 8 | 전도사 | 340 | 나무 지팡이 | 🌌 오로라 |
| 9 | 목사 | 520 | 빛나는 십자가 홀 | 🔥 황금 불꽃 |
| 10 | 담임목사 ✝ | 800 | 빛나는 십자가 홀 | 🔥 황금 불꽃 |

직위는 머리 위 이름표에 등급별 색 배지로 뜹니다 (장로 이상 오로라 그라데이션, 목사 이상 금색).

### 아바타

입장할 때 **일반 신자 / 개미 / 트럼프 / 머스크** 중에 고릅니다.
전부 팔다리가 따로 움직이는 리그라 걸으면 다리가 교차하고 팔이 반대로 흔들립니다.
트럼프는 얼굴에 **황금 $**, 머스크는 머리 위에 **빨간 테슬라 마크** (동상과 달리 번쩍이지 않는 평범한 재질).

## 설정

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `8080` | 서버 포트 |
| `ROOM_CAP` | `100` | 방당 최대 인원 |
| `ROOM_COUNT` | `1` | 예배실 개수 (사람 늘면 올리면 됩니다) |
| `ROTATE_MS` | `300000` | 추천 종목 교체 주기(5분) |
| `POLL_MS` | `30000` | 시세 갱신 주기 |
| `LIVE` | – | `0` 이면 전부 시뮬레이션 |

```bash
ROOM_COUNT=3 npm start      # 예배실 3개
```

## 다른 사람도 들어오게 하려면

### ⚠ Vercel 단독으로는 안 됩니다

Vercel 은 서버리스라 **웹소켓 연결을 계속 붙들고 있을 수 없습니다.** 멀티플레이가 동작하지 않습니다.

### 방법 1 — Render 한 곳에 통째로 (제일 간단, 추천)

리포에 `render.yaml` 이 들어 있습니다.

```bash
git init && git add -A && git commit -m "가즈아 교회"
# GitHub 에 리포를 만들고 push
git remote add origin https://github.com/<아이디>/<리포>.git
git push -u origin main
```

→ [render.com](https://render.com) 가입 → **New + → Blueprint** → 리포 선택 → 배포.
`https://가즈아-교회.onrender.com` 같은 주소가 나오고 그대로 공유하면 됩니다.
무료 플랜은 15분 접속이 없으면 잠들고 다음 접속 때 30초쯤 깨어납니다.

Railway, Fly.io, 일반 VPS 도 똑같이 `node server/index.js` 만 띄우면 됩니다.

### 방법 2 — Vercel(정적) + Render(웹소켓) 분리

굳이 Vercel 주소를 쓰고 싶으면 이 조합이 가능합니다.

1. 위 방법대로 Render 에 서버를 올립니다 (예: `gazua-church.onrender.com`)
2. `public/index.html` 의 설정 한 줄을 고칩니다
   ```js
   window.CHURCH_SERVER = 'gazua-church.onrender.com';
   ```
3. `public/` 폴더만 Vercel 에 올립니다

### 방법 3 — 지금 이 PC로 바로 (테스트용)

```bash
winget install --id Cloudflare.cloudflared
cloudflared tunnel --url http://localhost:8080
```

임시 공개 주소가 바로 나옵니다. 다만 **내 PC가 인터넷에 열리는 것**이고 창을 닫으면 끊깁니다.
친구 몇 명과 잠깐 테스트할 때만 쓰세요.

## 구조

```
server/
  index.js    HTTP 정적 서빙 + WebSocket + 방/동상/투표/고해 상태
  market.js   시세 엔진 (Yahoo 실시세 + 시뮬레이션 폴백)
  names.js    닉네임 자동 생성 · 직위 10단계
public/
  index.html  UI 셸 (+ CHURCH_SERVER 설정)
  css/style.css
  js/world.js  three.js 씬 — 예배당, 트황상, 전광판, 피라미드, 고해소, 아바타, 오라
  js/net.js    웹소켓 래퍼 (자동 재연결)
  js/audio.js  찬송가 오르간 합성
  js/main.js   입력 · 카메라 · UI 연결
```

- 위치는 **10Hz**로, 움직인 사람만 묶어 방 전체에 한 패킷
- 시세는 2초마다 가격만, 전체 캔들은 입장/교체 시에만
- 채팅·오물·청소·기원·고해 전부 서버에서 쿨다운과 길이 제한
- 명중 판정과 얼룩 좌표를 서버가 계산해 모두에게 같은 화면을 보냅니다

메모리 기반이라 서버를 재시작하면 오염도·투표·순위·고해가 초기화됩니다.
유지하려면 Redis 나 SQLite 를 붙이면 되고, 방을 여러 프로세스로 늘릴 거면 Redis pub/sub 으로 방 상태를 공유하면 됩니다.
